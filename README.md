## 🇬🇧 English

### ✨ Features
* 🔒 **Biometric Auto-Login:** Securely save your credentials using Android Keystore and log in instantly via Fingerprint or Face recognition.
* ⚡️ **Seamless Booking:** Minimal taps to select dates, directions, and trips from the timetable.
* 🤖 **Smart Session Management:** Automatically handles JAIST server redirects and session cookies in the background.

### 🚀 Installation
The easiest way to install the app is to visit our **[Official Website](https://sixima.download)** from your Android device and tap the download button. 
Alternatively, you can download the `app-release.apk` directly from the [Releases](#) tab.

## 💻 Repository Details & Development

This section is for developers who want to build, contribute to, or explore the source code.

### 📁 Project Structure
The core application logic is located in the `lib/` directory:
```text
lib/
├── constants/       # Static data (e.g., schedule_data.dart)
├── screens/         # UI layouts (login_screen.dart, booking_screen.dart)
├── services/        # Backend logic and API client (api_service.dart)
└── main.dart        # Flutter entry point
```

##🛠 Build Instructions

Ensure you have the Flutter SDK installed on your machine.

1. Clone the repository
   ```bash
   git clone https://github.com/ynk-samez/JAIBUS-app.git
   cd JAIBUS-app
   ```
2. Install dependencies
   ```bash
   flutter pub get
   ```
3. Build for production (Release APK)  
  ```bash
  flutter build apk --release
  ```

The generated APK will be located at build/app/outputs/flutter-apk/app-release.apk.
